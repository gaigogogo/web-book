# noteone v4.8 / EdgeOne 书签导航站

这是面向腾讯云 noteone / EdgeOne 的独立小版本，适合中国大陆访问。保留原书签功能，并增加备注书签的橙色提示标识，鼠标移到标识上即可快速查看备注。

本版本改用 EdgeOne 边缘函数与 Blob 存储，访问入口为 `book.090803.xyz`。原 Cloudflare 版本继续保留，两个版本的数据和用途可以分开维护。

Blob 名称 bookmarks，使用 strong 强一致读取。
前端通过边缘函数提供，保留访问锁；静态发布目录仅含占位页。

构建：node bump.cjs，然后 node build.cjs。
部署令牌和数据备份保存在项目外。

## 2026-10-13 新增能力

- 新建窗口粘贴 HTTP(S) URL 后自动读取网页标题；不覆盖手工填写的标题。可点击“获取标题与图标”重试。动态渲染页面、访问限制或超时时继续手填。图标后台抓取。
- 设置中有“快速添加小工具”：拖到电脑书签栏，在目标网页点击，带入 URL 与标题。已安装且浏览器支持 Web Share Target 时也可从系统分享进入；iOS 支持取决于浏览器，不承诺系统分享入口。
- “检查全部”每次4条、逐批保存。正常、失效（404/410）、待确认（超时/拦截/其他错误）分别标记，并保存 link_status/link_http_status/link_checked_at。点击状态可看检查时间。页面关闭会停止后续批次，已完成结果保留。
- 顶部“编辑模式”显示书签编辑/移动、删除、前移/后移和分类编辑/删除/排序按钮；书签触屏长按550ms也可打开菜单。用按钮替代触摸拖拽，不依赖移动浏览器的原生拖拽能力。
- Manifest、512px图标、Service Worker 已加入。设置“启用离线”主动缓存当前设备页面；API不缓存、不排队离线写入。已有快照支持弱网/断网只读；退出登录清理离线页与快照。iPad用Safari分享→添加到主屏幕。首次需联网登录并启用离线。

构建会将 manifest、sw.js、图标一同嵌入边缘函数。manifest/SW/安装图标公开，不包含用户书签。链接探测仅允许HTTP(S)公共域名、检查DNS与重定向，并设超时；不能把“待确认”当作确定死链。并发覆盖风险仍由整份Blob写入方式决定。
