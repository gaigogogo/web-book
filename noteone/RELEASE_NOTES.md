# v4.9-noteone · 2026-10-22

腾讯云 EdgeOne 版更新，CF v4.6 保留停止更新。

- 手机端（屏幕宽度不超过700px）隐藏分类导航，电脑端保留。
- 检查网址由每批4条提高到8条；DNS并行查询、同批同域名复用，网络异常自动重试一次。
- “继续检查”跳过近期结果，支持暂停及强制重新检查全部；降低每批页面重绘，减少中断后的重复工作。
- 正常/失效结果24小时内复用，待确认结果1小时内复用。书签旁检测文字在检查后10分钟自动隐藏，记录仍保留。
- 同步GitHub新账号与仓库地址为 gaigogogo/web-book，更新检查使用新的腾讯云版本文件。
- 建立后续版本递增、GitHub源码/ZIP/说明和博客同步发布流程。

使用方法：刷新网页后生效；设置中使用“继续检查”“重新检查全部”和“暂停”。超时或拒绝访问归为待确认，不应当作确定失效。

验证：链接检测批次、DNS复用、重试/暂停、缓存和离线逻辑测试已通过；此前线上8条抽测约3.6秒，不保证所有网站相同速度。手机隐藏分类按CSS宽度控制，未做本次iPad实机验证。

部署仍为全球可用区（不含中国大陆），Blob bookmarks。升级前建议导出JSON；不会自动改写现有书签数据。邮件密钥与发件地址由私有环境变量配置，不包含在下载包内。
